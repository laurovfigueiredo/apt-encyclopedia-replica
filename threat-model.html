Diamond Model of Intrusion Analysis

The Diamond Model (Caltagirone, Pendergast, Betz, 2013) defines an intrusion as an event where an adversary uses a capability over infrastructure against a victim. Each event connects four core features: Adversary, Capability, Infrastructure, and Victim.

Adversary

Who is behind the attack? (Actors, attribution, country, aliases)

Capability

What tools/techniques? (TTPs, malware, sophistication)

Infrastructure

How they communicate? (C2, domains, IPs, services)

Victim

Who is targeted? (Sectors, geography, organizations)
