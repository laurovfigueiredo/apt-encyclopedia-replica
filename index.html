Threat Model

Diamond Model of Intrusion Analysis

Caltagirone, Pendergast & Betz (2013): an intrusion is an event in which an adversary uses a capability over infrastructure against a victim. Every group profile below maps to these four features.

Adversary

Who is behind the attack — actor, aliases, attribution, country.

Capability

What they use — techniques, malware, sophistication level.

Infrastructure

How they communicate — C2, domains, IPs, services.

Victim

Who is targeted — sectors, industries, geography.

ATT&CK Mapping

Each group carries observed TTPs with tactic, technique ID (Txxxx), name and contextual usage where available — see the Diamond Model block on any group detail.
